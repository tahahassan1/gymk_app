# Cairo

Source: Google Fonts, `ofl/cairo/Cairo[slnt,wght].ttf`:
https://github.com/google/fonts/tree/main/ofl/cairo

The bundled static files contain upright instances at weights 400, 600 and 700.
They were produced with fontTools 4.67.0 `instantiateVariableFont`, pinning both
`wght` and `slnt` (0), with no glyph/artwork changes. Runtime needs no download.
The upstream SIL Open Font License and copyright are in `OFL.txt` and are bundled
with the app. Only these three used weights are declared in pubspec.
